# docs — 기획 문서

| 파일 | 내용 |
|---|---|
| [`game-design.md`](game-design.md) | 게임 기획서 (단일 원본) |
| [`decisions.md`](decisions.md) | 결정 기록. 무엇을 언제 왜 바꿨는지 |

## 기획을 바꾸는 방법

1. 브랜치를 만들고 `game-design.md`를 고칩니다.
2. 방향이 바뀌는 결정이면 `decisions.md`에 새 항목(D-번호)을 추가합니다.
3. 바뀐 기획 때문에 코드·맵을 고쳐야 하면 PR 설명에 적습니다.
4. PR을 올리고 팀원 모두에게 멘션으로 알린 뒤 직접 머지합니다 (D-015).

## AI 에이전트에게

- 기능을 구현하기 전에 이 폴더를 먼저 읽습니다.
- 사용자 요청이 기획서와 다르면, 구현하기 전에 그 차이를 사용자에게 알리고 기획서를 고칠지 묻습니다.
- 기획서에 없는 숫자(확률, 가격, 시간)를 정해야 하면 임시값으로 구현하고, PR 설명에 "임시값"이라고 적습니다.
